DataStart

Site Plan — WDD 131 Final Project

Site Name

DataStart

This name combines "Data" — the subject of the site — with "Start", communicating that the site is a beginning point for anyone new to the field. It is short, memorable, and clearly signals the beginner-friendly focus of the content.

Optional domain availability: datastartlearn.com

Site Purpose

DataStart is an informational learning resource designed to introduce beginners to data analytics. The site covers what data analytics is, the stages of the analysis process, popular tools (SQL, Python, Power BI, Tableau), and a structured learning roadmap for people who want to start a career in the field.

The site consists of three main pages:

  • Introduction to Data Analytics — core concepts, types of analytics, and the typical analysis workflow.
  • Data Analytics Tools and Skills — overview of key tools and the skills beginners should develop.
  • Beginner's Learning Roadmap — a step-by-step learning path, practice project ideas, and an interactive goal-setting form.

Interactive JavaScript features will allow visitors to filter tool cards, track a skills checklist, monitor learning progress, and receive a personalized summary of their learning goals.

Scenarios

Questions a typical beginner visitor might ask when landing on the site:

  1. I keep hearing about data analytics but I am not sure what it actually involves — where do I even begin?
  2. I have heard of Python, SQL, and Power BI — which one should I learn first as a complete beginner with no coding background?
  3. I want to break into data analytics within six months — what is a realistic step-by-step plan I can follow on my own?
